# Getting help with PepoMote

**English** · [Español](SUPPORT.es.md)

Having trouble connecting or getting a game to respond? You are welcome to ask in English or Spanish. You do not need to know how the code works.

## Start here

1. Check the [installation guide](README.md#install) and install the [latest published release](https://github.com/pepitolas13/PepoMote/releases/latest) on both the controller and the receiver. With two Android devices, update both.
2. Follow the guide for your setup: [Dolphin](docs/SETUP-DOLPHIN.md), [Cemu](docs/SETUP-CEMU.md), [Eden](docs/SETUP-SWITCH.md), [RetroArch](docs/SETUP-RETROARCH.md) or [Android server](docs/ANDROID-SERVER.md).
3. For platform-specific help, see [iPhone/iPad](docs/IOS.md), [Linux](docs/LINUX.md), [macOS beta](docs/MACOS.md), [Linux phones](docs/MOBILE-LINUX.md) and [troubleshooting](docs/TROUBLESHOOTING.md). Some detailed guides are currently in Spanish; ask in English if you need help with a step.

Use a trusted home network or your own hotspot. See the [security policy](docs/SECURITY.md) before using a shared network or configuring a VPN.

## Ask the community

- **[GitHub Discussions](https://github.com/pepitolas13/PepoMote/discussions):** setup questions, advice and sharing a working configuration. Answers stay searchable for the next person.
- **[PepoTech Discord](https://discord.gg/Vx3MPuMPxb):** conversation and help from the community.
- **[Issues](https://github.com/pepitolas13/PepoMote/issues/new/choose):** reproducible bugs, feature requests and documentation or accessibility improvements.

Not sure whether something is a bug or a setting? Start with Discussions or Discord. If you report it in the wrong place, we can help you find the right one.

## What helps us help you

Include the phone/tablet model and operating system, the receiver device and operating system, the PepoMote version on **both ends**, and the controller mode. For games, add the emulator version and the RetroArch core if applicable. Describe what you did, what you expected and what happened instead. Mention whether it happens every time and whether it worked in an earlier version.

A short recording or a relevant log excerpt can help. **Hide QR codes, pairing codes, tokens, credentials and personal information first.** Never send a game, ROM, BIOS or someone else's private files.

## Private reports

For vulnerabilities, follow the [security policy](docs/SECURITY.md). For harassment or other conduct concerns, follow the [Code of Conduct](CODE_OF_CONDUCT.md). You can contact Daniel (PepoTech) at [pepo@pepotech.es](mailto:pepo@pepotech.es) or by private message in [Discord](https://discord.gg/Vx3MPuMPxb). Keep ordinary setup questions in the community channels when possible so others can benefit from the answer.

PepoMote is an independent project. Help depends on the maintainer's and community's availability; there is no guaranteed response time. Thanks for your patience and for sharing what you learn.
