# SETUP-DOLPHIN

Se completa en el hito 3. Resumen previsto:

1. PepoMote (PC) en modo **Dolphin** — arranca el servidor DSU en `127.0.0.1:26760`.
2. Dolphin → Opciones → Controladores → **Alternate Input Sources**: activar, host `127.0.0.1`, puerto `26760`.
3. Wiimote emulado → cargar el perfil `assets/dolphin/PepoMote.ini` → listo.
4. Recentrar el puntero: botón diana del móvil.

Guía completa con capturas cuando el hito 3 cierre.
