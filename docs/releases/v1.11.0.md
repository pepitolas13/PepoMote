# PepoMote 1.11.0 — Actualizaciones y novedades dentro de la app

- **Aviso automático:** PepoMote busca nuevas versiones y muestra un aviso con las novedades y la opción de instalar o dejarlo para más tarde. Puedes volver a consultarlo desde Ajustes.
- **Novedades rápidas:** cada versión incluye un resumen breve en español e inglés dentro de la app. También aparece en la fuente de SideStore/AltStore.
- **Descarga con progreso:** comprueba el paquete antes de instalarlo, permite cancelar y ofrece reintentar si se corta la conexión.
- **Recuperación en escritorio:** el instalador conserva la versión anterior y comprueba el arranque de la nueva. Si falla, intenta recuperarla y volver a abrirla.
- **Instalación propia de cada sistema:** Android comprueba el paquete y abre su instalador; iPhone y iPad continúan en SideStore o AltStore. Las instalaciones administradas por Linux se actualizan con su gestor de paquetes.

**Para empezar, instala la 1.11.0 una vez en el mando y el receptor.** Las versiones anteriores no incorporan este instalador. Las siguientes versiones completas podrán utilizar el nuevo recorrido; esta publicación no actualiza por sí sola las apps antiguas.

Se conservan los ajustes y emparejamientos, el teclado integrado y el mando Wii con puntero de RetroArch introducidos en las últimas versiones. Android mantiene la confirmación del sistema y los requisitos de firma. En iOS, la tienda debe tener configurada la fuente de PepoMote y poder firmar la app; con Sideloadly se utiliza el ordenador.

[Guía de actualización y recuperación](https://github.com/pepitolas13/PepoMote/blob/main/docs/UPDATES.md) · [Instalación en iPhone y iPad](https://github.com/pepitolas13/PepoMote/blob/main/docs/IOS.md)

| Dispositivo | Descarga |
|---|---|
| Android 8.0+ | `PepoMote.apk` |
| Windows 10/11 | `PepoMote.exe` |
| Linux | `PepoMote-x86_64.AppImage` o `PepoMote-linux-x86_64.tar.gz` |
| Mac con chip Apple, macOS 13+ — beta | `PepoMote-macOS.dmg` |
| iPhone o iPad, iOS 15+ | `PepoMote.ipa`, mediante SideStore, AltStore o Sideloadly |
| Linux móvil ARM64 | `PepoMote-Mobile-aarch64.AppImage`, `pepomote-mobile_1.11.0_arm64.deb` o paquete musl |

La entrega incluye `update.json` y `SHA256SUMS.txt` con las huellas de los archivos publicados. Las comprobaciones automatizadas cubren las apps y los paquetes; macOS continúa como beta mientras se completa su validación en equipos reales.
